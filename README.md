# SolidWorks Projects

A collection of SolidWorks CAD models, parts, and assembly archives.

## Included Projects

- **Socket and Spigot Joint** (`Socket and spigot joint.zip`)
- **Coupling** (`the cuplin.zip`)
- **Knuckle Joint** (`the knukel.zip`)
- **Old Coupling** (`the ocupl.zip` / `the ocupl (2).zip`)
- **Single Tool Post** (`the Single Tool al.zip`)
- **Universal Coupling** (`thwe universal.zip`)

## Usage

Download and extract the corresponding `.zip` file to access the SolidWorks part (`.SLDPRT`), assembly (`.SLDASM`), and drawing (`.SLDDRW`) files.
