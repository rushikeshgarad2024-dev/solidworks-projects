### 📦 CAD Assemblies & Models
1. **Socket and Spigot Joint** (`Socket and spigot joint.zip`)
   - Cotter joint assembly connecting two coaxial rods subjected to axial tensile or compressive forces.
2. **Coupling** (`the cuplin.zip`)
   - Rigid/flange shaft coupling assembly designed for torque transmission between shafts.
3. **Knuckle Joint** (`the knukel.zip`)
   - Pin-connected joint designed to withstand tensile loads while allowing slight angular flexibility.
4. **Old Coupling** (`the ocupl.zip` / `the ocupl (2).zip`)
   - Alternative coupling design configurations and components.
5. **Single Tool Post** (`the Single Tool al.zip`)
   - Lathe machine single tool post holder assembly for securing cutting tools.
6. **Universal Coupling / Joint** (`thwe universal.zip`)
   - Hooke's joint assembly connecting intersecting shafts to transmit rotational power.

## 🛠️ How to Use

### Using CAD Models:
1. Clone or download this repository:
   ```bash
   git clone https://github.com/rushikeshgarad2024-dev/solidworks-projects.git
   ```
2. Extract the desired project `.zip` file.
3. Open the assembly (`.SLDASM`) or part (`.SLDPRT`) files in **Dassault Systèmes SolidWorks**.

### Running SolidWorks Macros:
1. Extract `All_SolidWorks_Moving_Macros.zip`.
2. In SolidWorks, go to **Tools > Macro > Run...** (or press **Alt + F8** / **Alt + F11** for VBA editor).
3. Select the corresponding `.bas` macro to automatically model and animate the assembly.
4. Refer to `README_How_To_Run_And_Move.txt` inside the archive for detailed instructions.
